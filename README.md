# figma-component-library-6700-6709

Container: storybook_frontend

Quick start:
- cd storybook_frontend
- npm install
- npm start   # Storybook v8 on 0.0.0.0:3000
- npm run start:storybook  # same as npm start
- npm run start:app  # CRA on 3300

Details:
- Storybook dev server: http://localhost:3000 (binds to 0.0.0.0 for container checks)
- CRA dev server: http://localhost:3300
- Build Storybook: npm run build-storybook

For more, see storybook_frontend/README.md and storybook_frontend/STORYBOOK.md.
